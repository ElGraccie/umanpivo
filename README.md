# Уманьпиво — концепт сайту

Концепт редизайну сайту пивоварні «Уманьпиво» ([umanpivo.ua](https://umanpivo.ua)): одна сторінка з шапкою-сценою, каталогом, конструктором BeerBox, кошиком і сезонними темами.

> Це концепт: оплата й оформлення замовлення не підключені. Фото товарів, логотип, асортимент і ціни взято з umanpivo.ua станом на 17.11.2026.

## Що в репозиторії

| Шлях | Призначення |
|---|---|
| `index.html` | Готовий сайт: одна сторінка, фото каталогу вбудовані |
| `t/<тема>/*.webp` | Запечені шари шапки для тем; завантажуються лише для активної теми |
| `source/` | Вихідники збірки (див. нижче) |

## Сезонні теми

Тема обирається автоматично за **київським часом** (кнопка «Авто» в шапці):

| Період | Тема |
|---|---|
| 1 березня – 31 серпня | Звичайна |
| 1 вересня – 30 листопада | Осінь |
| 1 грудня – 29 грудня і 6 січня – кінець лютого | Зима |
| 30 грудня – 5 січня | Новий рік |

Кнопки «Звичайна», «Осінь», «Зима», «Новий рік» дозволяють обрати тему вручну; вибір зберігається в `localStorage` (ключ `up-theme2`). Кнопка «Ефекти» вмикає й вимикає анімацію та паралакс. На слабких пристроях, при `prefers-reduced-motion` і в режимі економії трафіку вмикається полегшений режим (ключ `up-fx`).

Окрім шапки, тема змінює кольори секцій, фон і декор нижче: листя восени, бурульки взимку, гірлянда на Новий рік.

## Запуск

Статична сторінка, збірка не потрібна. Віддайте корінь репозиторію будь-яким статичним сервером, наприклад:

```bash
python3 -m http.server 8000
```

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.

## Збірка з вихідників

```bash
python3 source/build_site.py
```

Потрібен лише Python 3 зі стандартною бібліотекою. Скрипт збирає `index.html` у корені з:

- `source/base/index.html` — базова сторінка: каталог, BeerBox, кошик, фото;
- `source/src/` — CSS і JS шапки та тем, favicon-и;
- `source/inner.py` — сезонне оформлення нижче шапки.

Шари `t/` мають лежати на місці. Збірка відтворює опублікований `index.html` байт у байт.

## Шари шапки

`source/layers/` — скрипти, якими запечено WebP-шари (SVG → WebP через headless Chrome; потрібні Playwright, Pillow і NumPy). Це довідкові матеріали: для звичайної збірки вони не потрібні.
